# Zig Mini Lisp - プロジェクト概要

## はじめに

Zig Mini Lisp は、Zig プログラミング言語で実装されたミニマリストな Lisp インタープリタです。このプロジェクトは、Zig
のメモリ安全性、高パフォーマンス、および低レベル制御を活用しながら、シンプルな Lisp のような言語インタープリタを構築する方法を示します。

## プロジェクト構造

### コアコンポーネント

1. **トークナイザ**: Lisp の構文をトークン（数値、シンボル、括弧）に分解します。
2. **パーサ**: トークンを抽象構文木 (AST) に変換します。
3. **メモリ管理**: 古典的な Lisp の cons セル（car/cdr ペア）を使用したヒープベースのアプローチを採用しています。
4. **シンボルテーブル**: シンボルの解決と関連付けを管理します。
5. **評価器**: 解析された Lisp 式を実行します。

### 主なファイル

- `src/main.zig`: テストを含むインタープリタロジックのメイン実装ファイル
- `build.zig`: プロジェクトのビルド設定

## ビルドと実行

### 前提条件

- Zig コンパイラ（最新の安定版を推奨）

### ビルドコマンド

```bash
# プロジェクトのビルド
zig build
# アプリケーションの実行
zig build run
# 引数付きで実行
zig build run -- arg1 arg2
# テストの実行
zig build test
```

## 機能

- 基本的な Lisp 構文の解析
- 数値リテラルやシンボルのサポート
- Cons セルベースのメモリ構造
- シンプルなシンボル管理

## 開発ガイドライン

### コードスタイル

- Zig スタイルガイドに従う
- 意味のある変数名や関数名を使用する

### テスト

- すべての新機能に対して単体テストを書く
- 解析や評価のエッジケースをテストでカバーする
- 変更を提出する前にテストスイートを実行する

### メモリ管理

- ヒープベースのメモリアプローチに注意を払う
- メモリセルの適切な初期化とクリーンアップを保証する
- シンボルテーブルでのメモリリークの可能性に注意する
